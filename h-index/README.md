# h-index算出
## h-indexとは
研究者や機関の発表した論文について、発表論文数と被引用回数とのバランスを見た指標。10本論文を発表していて、そのでれもが10より多く引用されている場合はh-index=10となる。詳細はWikiなどを参照。

### 通常のソートで求める方法（sort_search.py）
直感的に求める方法。各論文の被引用数をソートし、降順にh-indexをカウントアップしていって、被引用数以上となったらそれをh-indexとする方法

### バケツソート（度数ソート）を利用する方法（bucket_sort.py）
バケツソートを利用することで、被引用数をソートすることなく求める。
#### **・アルゴリズムの流れ**

1.  **「バケツ」を用意する**: 論文の総数を `n` としたとき、サイズ `n+1` の配列（バケツ）を用意。この配列は、各論文の被引用数を記録するために使う。

      * `buckets[i]` は、引用回数が `i` 回である論文の数を示す。
      * 被引用回数が `n` を超える論文は、h-indexの計算上 `n` 回と見なして問題ないため、すべて `buckets[n]` に加算。

2.  **論文をバケツに入れる**: 元の被引用数リストを一度だけ見て、各論文を対応するバケツに入れる。

3.  **後ろから数え上げる**: バケツを後ろ（引用数が多い方）から検索。論文数を累積しながら、「論文の累計本数が、その時点での引用回数（=バケツのインデックス）以上になる」箇所が、その引用回数がh-index。

### 比較

| | ソートを用いる方法 | カウント（バケツ）を用いる方法 |
|:--- |:--- |:--- |
| **計算量** | $O(n \log n)$ | $O(n)$ |
| **アプローチ** | 全体を並べ替えてから探す | 引用数を数え上げてから探す |
| **長所** | 実装が直感的で分かりやすい | 論文数が膨大でも非常に高速 |
